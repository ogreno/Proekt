# Proekt — музыкальный плеер на Kotlin Multiplatform

Один проект для Android и iPhone. Общие экраны написаны на Compose Multiplatform, общая логика — на Kotlin.

## Запуск на Android

1. Распакуйте архив в отдельную папку и откройте её в Android Studio.
2. Выберите JDK 21 в настройках Gradle.
3. Дождитесь синхронизации. При первом запуске нужен интернет для зависимостей.
4. Подключите Android-телефон с USB-отладкой, выберите конфигурацию app и нажмите Run.
5. Для сохранения прежней библиотеки устанавливайте обновление поверх Proekt с той же подписью. Приложение использует прежнюю базу music_database и читает очередь версии 1.1.

Поддержка Android начинается с версии 7.0 (API 24). compileSdk 36 относится к инструментам сборки.

## Запуск на iPhone

Для этого этапа нужен Mac с Xcode и JDK 21. Windows подходит для работы с исходниками и Android-сборки.

1. Перенесите всю папку проекта на Mac.
2. Откройте iosApp/iosApp.xcodeproj в Xcode.
3. Выберите схему Proekt.
4. В Signing & Capabilities выберите свою Team. При необходимости задайте уникальный Bundle Identifier.
5. Выберите iPhone или симулятор iPhone на Apple Silicon и нажмите Run.
6. Xcode запустит Gradle и соберёт общий Kotlin-фреймворк Shared.
7. Если Xcode не находит Java, задайте JAVA_HOME для установленного JDK 21 в окружении сборки.
8. Добавьте песню из приложения «Файлы» и пройдите сценарии из CHECKLIST.md.

В проекте настроены физические iPhone arm64 и симуляторы arm64. Для Intel Mac отдельная цель симулятора не настроена. Минимальная версия iOS в Xcode-проекте — 16.

Исходники iPhone-части подготовлены. Сборка Xcode и проверки на iPhone требуют отдельного выполнения на Mac. До этой проверки поддержку iPhone следует считать неподтверждённой.

## Как читать код

Начните с shared/src/commonMain/kotlin/com/example/proekt/shared.

- Models.kt содержит трек, плейлист, библиотеку и состояние плеера.
- MusicApp.kt переключает экраны и показывает мини-плеер.
- TrackScreens.kt содержит библиотеку, избранное, поиск и меню трека.
- PlaylistScreens.kt содержит создание плейлиста и выбор песен.
- PlayerScreen.kt показывает плеер, очередь и таймер. При повороте используется другая раскладка.
- LibraryController.kt меняет библиотеку и сохраняет результат.
- PlayerController.kt управляет очередью, повтором, перемешиванием, позицией и таймером.
- PlatformServices.kt описывает, что платформа должна уметь делать с файлами, хранилищем и звуком.

Android-код находится в app/src/main/java/com/example/proekt. AndroidStorage использует Room и прежнюю схему таблиц. AndroidAudioImporter открывает системный выбор файла и читает теги. AndroidAudioEngine воспроизводит аудио через ExoPlayer. PlaybackService отвечает за фоновую службу и карточку в шторке.

iPhone-код находится в shared/src/iosMain. IosStorage сохраняет библиотеку в JSON-файле. IosAudioImporter копирует выбранное аудио в папку приложения и проверяет повторный импорт по содержимому. IosAudioEngine использует AVPlayer. MainViewController подключает общий интерфейс и Пункт управления iOS.

В iosApp находится небольшой SwiftUI-вход для Xcode. Экраны и логика плеера остаются на Kotlin.

## Основные сценарии

- Импорт аудио, чтение тегов и длительности.
- Поиск по названию и исполнителю в библиотеке, избранном и внутри плейлиста.
- Поиск плейлистов по названию.
- Создание и удаление плейлистов, добавление и удаление треков.
- Редактирование названия и исполнителя внутри библиотеки.
- Очередь, «Играть следующим», «В конец очереди», удаление из очереди.
- Повтор, случайный порядок, таймер на 15/30/60 минут или до конца трека.
- Восстановление трека, очереди и позиции на паузе.
- Фоновое воспроизведение и системное управление.

«Играть следующим» выключает случайный порядок и повтор одного трека, чтобы следующий выбранный трек действительно заиграл. При поиске воспроизведение использует очередь исходного списка. Таймер «до конца трека» отменяется при ручном выборе другого трека.

Библиотека хранится отдельно на каждом телефоне. Автоматическая синхронизация музыки между устройствами в проекте не предусмотрена.

## Проверка общей логики

Из корня проекта:

Windows:
~~~powershell
.\gradlew.bat :shared:testAndroidHostTest :app:assembleDebug
~~~

Mac:
~~~sh
/bin/sh ./gradlew :shared:testAndroidHostTest :app:assembleDebug
~~~

Тесты находятся в shared/src/commonTest. Они проверяют восстановление без автозапуска, повторный импорт, очередь, таймер, удаление и ошибку сохранения. Отдельно необходима проверка интерфейса и системного воспроизведения на устройствах.
